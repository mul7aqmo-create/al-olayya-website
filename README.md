# وحدات العليا السكنية - Al-Olayya Residential Units

موقع عقاري متجاوب بالكامل لمشروع وحدات العليا السكنية في حي العليا بالرياض.

## النشر على Netlify

1. اذهب إلى [netlify.com](https://netlify.com)
2. اسحب مجلد المشروع أو اربطه بهذا المستودع
3. سيتم نشر الموقع تلقائياً

## المواصفات التقنية

- HTML/CSS/JS بدون أي إطارات عمل
- عربي RTL بالكامل
- متجاوب: Desktop / Tablet / Mobile (390px)
- خطوط: Alexandria للعناوين + IBM Plex Sans Arabic للنصوص
- دعم `prefers-reduced-motion`
- SEO محسّن مع Open Graph
- زر واتساب عائم
- خريطة Google Maps مدمجة
